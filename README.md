# La Strega Dony e il Berserker dell’Occulto

Sito ufficiale pubblico di **La Strega Dony e il Berserker dell’Occulto**, videogame action horror occulto 2D attualmente in sviluppo.

Il progetto segue due protagonisti fuori dagli schemi, chiamati ad affrontare presenze demoniache, luoghi infestati, creature corrotte e minacce soprannaturali in un’avventura oscura a scorrimento bidimensionale.

## Stato del progetto

**Stato:** in sviluppo  
**Genere:** action horror 2D / avventura occulta  
**Piattaforma prevista:** PC  
**Fase attuale:** prototipazione, sviluppo visivo, sistemi di gameplay, costruzione narrativa e worldbuilding
